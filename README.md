# QA E-commerce Manual Testing

Projeto de Quality Assurance desenvolvido para demonstrar conhecimentos práticos em testes manuais de uma aplicação de comércio eletrônico.

## Objetivo

Validar os principais fluxos de uma aplicação de e-commerce, identificando possíveis defeitos e verificando se os requisitos funcionais são atendidos.

## Escopo

- Login
- Cadastro
- Produtos
- Carrinho
- Checkout
- Pagamento
- Finalização da compra

## Técnicas de Teste

- Testes funcionais
- Testes positivos
- Testes negativos
- Testes exploratórios
- Testes de regressão
- Smoke Testing
- Análise de risco
- Criação de casos de teste
- Registro de bugs
