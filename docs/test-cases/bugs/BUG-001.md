# BUG-001 — Login com senha inválida

## Título

Sistema permite autenticação utilizando senha incorreta.

## Ambiente

- Ambiente: Homologação
- Navegador: Google Chrome
- Sistema operacional: Windows 11
- Tipo: Web

## Pré-condição

Possuir usuário previamente cadastrado.

## Passos para reprodução

1. Acessar a tela de login.
2. Informar e-mail válido.
3. Informar senha incorreta.
4. Clicar em "Entrar".

## Resultado esperado

O sistema deve bloquear o acesso e informar que as credenciais são inválidas.

## Resultado atual

O sistema permite acesso utilizando senha incorreta.

## Severidade

Crítica

## Prioridade

Alta

## Status

Aberto

## Impacto

O problema pode permitir acesso indevido à conta de um usuário.
