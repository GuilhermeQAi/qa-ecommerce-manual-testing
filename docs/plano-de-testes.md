# Plano de Testes

## 1. Objetivo

Garantir a qualidade dos principais fluxos funcionais da aplicação de e-commerce.

## 2. Objetivos dos testes

- Identificar defeitos;
- Validar regras de negócio;
- Verificar os principais fluxos do usuário;
- Validar mensagens de erro;
- Garantir que informações sejam processadas corretamente.

## 3. Escopo

### Dentro do escopo

- Login
- Cadastro
- Produtos
- Carrinho
- Checkout
- Pagamento
- Finalização da compra

### Fora do escopo

- Testes de infraestrutura;
- Testes de carga;
- Testes de segurança avançados;
- Testes de performance avançados.

## 4. Tipos de teste

- Teste funcional
- Teste negativo
- Teste exploratório
- Teste de regressão
- Smoke test

## 5. Critérios de entrada

- Aplicação disponível;
- Requisitos definidos;
- Ambiente acessível;
- Dados de teste disponíveis.

## 6. Critérios de saída

- Casos planejados executados;
- Bugs analisados;
- Resultados documentados;
- Evidências registradas.

## 7. Riscos

- Falhas no login;
- Erros no cálculo do carrinho;
- Falhas no pagamento;
- Pedido duplicado;
- Dados incorretos no checkout.
