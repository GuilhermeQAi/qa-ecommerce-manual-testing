# Requisitos Funcionais

## RF001 — Login

O sistema deve permitir que usuários cadastrados realizem login utilizando e-mail e senha válidos.

## RF002 — Cadastro

O sistema deve permitir o cadastro de novos usuários.

## RF003 — Produtos

O usuário deve conseguir visualizar produtos disponíveis para compra.

## RF004 — Carrinho

O usuário deve conseguir adicionar, remover e alterar a quantidade de produtos.

## RF005 — Checkout

O usuário deve conseguir informar endereço e revisar os produtos antes da compra.

## RF006 — Pagamento

O sistema deve permitir a realização do pagamento através dos métodos disponíveis.

## RF007 — Pedido

Após o pagamento aprovado, o sistema deve gerar um pedido.

## RF008 — Segurança

O sistema não deve permitir acesso à conta utilizando credenciais inválidas.
